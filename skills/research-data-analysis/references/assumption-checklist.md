# 前提检验清单

每个检查项都要写明：检验方法、实际结果（数值）、是否满足、处理建议（待研究者确认）。没做的检查标注"未检查"及原因。以下为通用起步清单（暂定做法），请用你的方法书补充出处。

## 所有分析通用

- [ ] 样本量：总样本、每个模型实际进入的样本（缺失导致的列表删除）
- [ ] 缺失：各变量缺失率；缺失是否与关键变量相关（不能默认随机缺失）
- [ ] 异常值：IQR / 标准化残差 / Cook's D；先核对是否为录入错误，再讨论处理
- [ ] 重复记录：完全重复行；面板中 id–time 重复
- [ ] 变量编码：反向题是否已反向、类别变量参照组、单位是否一致

## OLS 回归

- [ ] 线性关系：残差 vs 拟合值图
- [ ] 异方差：Breusch-Pagan / White 检验 → 稳健标准误
- [ ] 多重共线性：VIF（常用参考值 >10，严格时 >5）；交互项前考虑中心化
- [ ] 残差正态：大样本下影响较小，小样本需检查（Q-Q 图）
- [ ] 误差独立：嵌套/面板数据需聚类标准误
- [ ] 内生性：列出可能来源（遗漏变量、反向因果、选择偏差、测量误差）及应对

## Logit / Probit

- [ ] 事件数是否足够（每个自变量对应的事件数不宜过少）
- [ ] 完全分离 / 准完全分离
- [ ] 报告边际效应，而不只报告系数或 OR
- [ ] 交互项的解释在非线性模型中需特别处理

## 面板数据

- [ ] 面板是否平衡；样本流失是否有系统性
- [ ] 组内变异：关键自变量在个体内是否有足够变化（FE 依赖组内变异）
- [ ] FE vs RE 选择依据
- [ ] 序列相关、截面相关 → 聚类标准误 / Driscoll-Kraay
- [ ] 自变量是否滞后以缓解反向因果

## 问卷数据 / SEM

- [ ] 信度：Cronbach's α、CR（常用参考值 ≥ 0.7）
- [ ] 收敛效度：因子载荷、AVE（≥ 0.5）
- [ ] 区分效度：Fornell-Larcker、HTMT（< 0.85 或 0.90）
- [ ] 共同方法偏差：程序控制 + 统计检验（Harman 单因子仅作初步参考，标记变量法 / 潜在方法因子更有力）
- [ ] 模型拟合（CB-SEM）：χ²/df、CFI、TLI、RMSEA、SRMR
- [ ] 测量模型先于结构模型
- [ ] 反映型 vs 形成型构念是否设定正确

## 调节与中介

- [ ] 调节：交互项显著后做简单斜率；画交互图；不只看交互项 p 值
- [ ] 中介：Bootstrap 置信区间（≥ 5000 次）；说明中介的时序与因果假设是否成立

## 因果识别方法

- [ ] DID：平行趋势检验、事件研究图、处理时点是否交错（交错 DID 需用新估计量）
- [ ] 工具变量：相关性（第一阶段 F 值）、排他性论证（无法统计检验，需理论论证）
- [ ] 断点回归：带宽选择、驱动变量是否被操纵（密度检验）
- [ ] 倾向得分匹配：匹配后平衡性检验；只能处理可观测变量偏差

## 关键结果必做（v0.2 新增）

- [ ] **影响力单位**：逐个剔除聚类单位（leave-one-cluster-out），报告系数范围；至少剔除影响最大的单位（如美国、最大企业）后重估。领先–滞后/事件研究图逐个检查
- [ ] **一次只改一个设定**：比较两列时，若同时改变了相关结构、固定效应、控制变量、样本或标准误类型，逐项单独改变并报告各自的影响
- [ ] **工具变量补充报告**：工具变量非零单位数；简约式（Y 对 IV）；与主回归相同固定效应下的 2SLS；聚类情形下的有效 F（Montiel Olea–Pflueger），而不只是与 Stock-Yogo 临界值比较
- [ ] **中介分析**：处理变量若用第一阶段预测值，检查其中工具变量部分占多少方差（`xb` 与 `xbd` 的区别）；中介→结果路径在加入固定效应后是否仍然成立；敏感性参数 ρ 的临界值大小如何解读（|ρ| 很小 = 结论脆弱）
- [ ] **异质性**：组间差异要用交互项或系数差异检验，不能只比较两组各自的显著性
- [ ] **缺失码**：−999、9999 等是否被当作真实数值参与缩尾或回归

## 稳健性检验（按需选）

- [ ] 替换因变量/自变量测量
- [ ] 换模型设定（备选方法）
- [ ] 子样本、剔除特殊年份/行业
- [ ] 缩尾处理前后对比
