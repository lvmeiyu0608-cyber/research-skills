# 方法选择决策树

用法：按"研究问题 → 数据结构 → 因变量类型"依次判断，得到候选方法。这是起步用的通用框架（暂定做法），应以你的方法书、课程材料和导师要求为准逐条替换或补充，并标注来源。

## 1. 先问研究问题是哪一类

| 研究问题 | 典型方法方向 |
|---|---|
| 描述现状/分布 | 描述统计、交叉表、可视化 |
| X 与 Y 是否相关 | 相关、回归（不作因果表述） |
| X 是否导致 Y（因果） | 需要识别策略：实验、DID、工具变量、断点回归、面板固定效应 + 时序 |
| X 对 Y 的作用是否随 W 改变（调节） | 交互项回归；连续调节变量做简单斜率 / Johnson-Neyman |
| X 通过 M 影响 Y（中介） | Bootstrap 间接效应；注意中介因果假设更强 |
| 潜变量之间的关系（问卷量表） | CB-SEM（理论检验、大样本）/ PLS-SEM（预测导向、复杂模型、形成型构念） |
| 分组差异 | t 检验、ANOVA、非参数检验 |

## 2. 再看数据结构

| 数据结构 | 需要注意 |
|---|---|
| 截面数据 | 内生性、遗漏变量；同源问卷需查共同方法偏差 |
| 面板数据（个体 × 时间） | 固定效应 vs 随机效应（Hausman 检验仅作参考）；按个体聚类标准误；时间固定效应 |
| 嵌套数据（员工在团队、企业在行业） | 多层模型（HLM）或聚类标准误；ICC(1) / rwg 支持聚合 |
| 实验数据 | 随机化检查、操纵检验、注意力检查 |
| 文本/行为日志等二手数据 | 测量构造过程需完整说明；构念效度 |

## 3. 最后看因变量类型

| 因变量 | 候选模型 |
|---|---|
| 连续 | OLS；面板用 FE/RE |
| 二分（0/1） | Logit / Probit；线性概率模型作稳健性 |
| 计数（专利数、投诉数） | 泊松；过度离散用负二项；大量零值考虑零膨胀 |
| 有序（满意度等级） | 有序 Logit / Probit |
| 截断/删失（研发投入大量为 0） | Tobit；或两部分模型 |
| 比例（0–1 之间） | 分数 Logit（fractional logit） |
| 事件发生时间（存活、退出） | 生存分析（Cox 模型） |

## 4. 记录选择依据

每次选择都写成：
> 因变量为 __（类型），数据为 __（结构），研究问题属于 __（类型）→ 主方法 __；备选 __（用于稳健性检验）。来源：[本项目要求 / 方法文献：作者-年份-章节 / 暂定做法]
